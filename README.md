## 我在做的事

**Palimpsest** —— 本地优先的开源 AI 长期记忆系统。**覆而不失，改写可溯。**

语义向量 + FTS5 全文 + 知识图谱三路混合检索、RRF 融合排序；新事实覆盖旧事实，但旧版本经 `REVISED_BY` 版本链可追溯；REST / MCP / CLI 三接入共用一内核，21 个工具能力对等。数据在自己机器上，按 MCP 标准协议对外，换宿主不换记忆。

## 我在琢磨的三件事

| 判断 | 一句话 |
| :--- | :--- |
| **agent + memory = assistant** | 模型给能力，工具给手脚，**记忆给连续性**——没有记忆的 agent，每次见面都是第一次见你 |
| **高质量的记忆，是 AI 涌现的土壤** | 长程任务里缺的往往不是参数，而是可信、可检索、可追溯的上下文 |
| **记忆的所有权属于用它的人** | 本地优先不是洁癖，是换模型、换工具、换机器时不失忆的前提 |
